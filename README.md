## 📖 Descripción

REDESAAL es un sitio web desarrollado en HTML y publicado mediante GitHub Pages. El proyecto tiene como finalidad ofrecer una plataforma web sencilla, accesible y de fácil mantenimiento para la presentación de información institucional y contenidos digitales.

## 🎯 Objetivos

- Publicar contenido web de forma rápida y eficiente.
- Brindar una interfaz amigable para los usuarios.
- Mantener un sitio web ligero y compatible con cualquier navegador moderno.
- Facilitar futuras ampliaciones mediante CSS y JavaScript.

## ✨ Características

- Sitio web estático.
- Diseño adaptable (Responsive).
- Compatible con los principales navegadores.
- Publicado con GitHub Pages.
- Código organizado y fácil de mantener.

## 🛠 Tecnologías utilizadas

- HTML5
- CSS3 *(si aplica)*
- JavaScript *(si aplica)*
- Git
- GitHub
- GitHub Pages

## 🚀 Instalación

### Clonar el repositorio

```bash
git clone https://github.com/USUARIO/REDESAAL.git
```

Ingresar al proyecto

```bash
cd REDESAAL
```

Abrir el archivo

```
index.html
```

en cualquier navegador web.
